# Бот: «ГДЕ ВАША ТОЧКА РОСТА В КАРЬЕРЕ И ДОХОДЕ»

Telegram-бот для Анны Ларшиной. Пользователь проходит тест из 7 вопросов,
бот автоматически отправляет Анне результаты (имя, телефон, все 7 ответов).

## Переменные окружения карьерного бота

| Переменная    | Описание                                      |
|---------------|-----------------------------------------------|
| `BOT_TOKEN`   | Токен Telegram-бота от @BotFather             |
| `ANNA_CHAT_ID`| Числовой chat_id Анны в Telegram              |

## Как получить ANNA_CHAT_ID

1. Анна должна написать боту `/start` один раз
2. Бот ответит: «Ваш chat_id = XXXXXXXXX»
3. Скопируйте это число и вставьте в переменную `ANNA_CHAT_ID` на Railway
4. Сделайте Redeploy

## Внутренний AI-бот агентства

В том же Render Worker запускается второй Telegram-бот для сотрудников агентства.
Он помогает собирать семантику, писать объявления, решать обычные рабочие задачи
и создавать изображения. Доступ ограничен списком Telegram ID.

Обязательные переменные:

| Переменная | Описание |
|------------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен внутреннего Telegram-бота |
| `OPENAI_API_KEY` | Ключ OpenAI API |
| `ALLOWED_TELEGRAM_USER_IDS` | Разрешённые Telegram ID через запятую |
| `ADMIN_TELEGRAM_USER_IDS` | Telegram ID администраторов через запятую |

Дополнительные настройки находятся в `.env.example` проекта внутреннего бота.
По умолчанию дневной лимит изображений равен пяти на одного сотрудника.
Денежный лимит составляет $0,50 в сутки на сотрудника и $4,50 на всех
пользователей за скользящие семь суток. Команда `/limit` показывает остатки,
а `/stats` выводит расходы администратору.

## Деплой на Render

Render запускает `launcher.py` через `Procfile`. Один Worker поддерживает оба бота.
Переменные окружения задаются в разделе Environment сервиса.

## Структура бота

- Шаг 1: Приветствие + кнопка Старт
- Шаг 2: Подписка на канал + кнопка «Подписался»
- Шаг 3: Запрос номера телефона (кнопка «Поделиться номером»)
- Шаг 4: Вводная часть теста + кнопка «Начать тест»
- Шаги 5–11: Вопросы 1–7 (кнопки A/B/C/D)
- Шаг 12: Финал — сообщение пользователю + автоотправка Анне
